# 첫 플롭 결정의 행동가치 학습

2026년 11월 26일 16:17 KST, 480회 모델에서 첫 플롭 결정을 담당하는 새 가중치 학습을 마쳤다. 시드 342·343·344에 각자의 모델을 둔다. 프리플롭과 첫 플롭 결정 이후의 플레이는 해당 시드의 480회 전략을 사용한다.

### 학습 데이터

새 자기대전 카드에서 시드당 첫 플롭 결정 1,024곳을 모은다. 플레이어가 실제로 볼 수 있는 자신의 패, 공개 카드와 베팅 상황이 학습 입력이다. 각 상황에서 기존 모델의 행동 메뉴에 있는 폴드, 체크 또는 콜, 반 팟·한 팟·올인의 합법적인 선택을 모두 시뮬레이션한다. 레이즈 한도에 걸려 액수가 같아지면 하나의 선택으로 처리한다. 기존 모델의 선택 확률이 0이었던 행동도 학습한다.

하나의 상황에서 모든 선택에 같은 네 번의 후속 카드와 상대 행동 난수를 적용한다. 각 갈래를 게임 끝까지 진행해 받은 칩으로 행동가치 표본을 만든다. 학습자의 이후 결정은 480회 전략을 따른다. 상대 좌석은 매 판 현재 기준인 480회를 절반의 확률로, 과거 300·360·420회를 각각 1/6의 확률로 사용한다. 이 구성은 학습 표본을 생성하기 위한 것이다. [학습 출발점과 카드 범위](../reports/preflop-followup/480-v1/flop-repair-20261126/training-design.json)

### 학습 결과와 실행

세 시드에서 가능한 행동 12,845개에 대한 가치 표본을 얻었다. 총 51,380개 갈래를 끝까지 플레이했고 가중치를 1,536번 업데이트했다. 시드마다 학습 상황을 독립적으로 재표집해 작은 행동가치 신경망 두 개를 훈련했다. 두 신경망 모두 같은 선택을 기존 전략보다 유리하다고 추정하고 정해진 여유를 넘을 때만 그 선택에 주는 확률을 늘린다. 한 번에 옮기는 확률 질량은 최대 25%다. 학습에 사용한 3,072곳 중 1,123곳에서 실제 선택 확률이 바뀌었다. 실전 승률의 변화는 미측정이다.
