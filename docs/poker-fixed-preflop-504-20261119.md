# 480회 프리플롭을 고정한 504회 자기대전

## 결과를 보기 전에 정한 계획

개선이 확인된 480회 전문 후보에서 새 자기대전을 24회 이어간다. 지난 고정 표본 실험에서 프리플롭에 256회 추가 업데이트를 적용하자 혼합·NoRegrets 상대 점수가 하락했다. 이번에는 첫 행동을 포함한 프리플롭 정책 전체를 동결하고, 같은 정책으로 실제 게임을 하며 새 표본을 수집해 플롭·턴·리버를 학습한다. [직전 실험 결과](poker-preflop-dose-20261119.md)

| 항목 | 고정한 내용 |
| --- | --- |
| 출발 | 고정 시드 342·343·344 각각의 480회 전문 프리플롭 가중치와 원본 480회 포스트플롭 가중치·복구 상태 |

| 피팅 | 포스트플롭 표본만 사용해 회차당 768회 업데이트, 배치 512개, 학습률 0.001 |

## 콜·폴드 진단

직전 256회 추가 피팅에서 발견한 콜→폴드 변화를 독립적인 새 카드 2,000묶음(2037900000~2037901999)에서 조사한다. 출발 후보와 256회 후보가 동일한 공개 행동을 따라가다 처음으로 콜과 폴드를 다르게 선택한 시점만 골라, 같은 패와 공개 상황에서 두 선택의 최종 손익을 비교한다. 콜 이후에는 고정한 480회 정책을 사용한다. 포지션·콜 비용·팟 오즈와 기존 표본 분포를 함께 본다. 이 진단은 학습이나 최종 504회 평가에 영향을 주지 않는다.

## 실행 기록

원본은 `artifacts/preflop-followup/480-v1/fixed-preflop-504`에 보관한다. `training-status.json`과 `evaluation-status.json`은 각 단계 상태, `stage-ready.json`은 세 시드의 학습 완료, `summary.json`은 평가 종료, `final-audit.json`은 독립 검산 기록이다. 콜·폴드 진단은 같은 상위 폴더의 `call-fold-diagnosis`에 보관한다.

## 콜과 폴드의 실제 비교 결과

11월 19일 16:51 KST, 새 카드 2,000묶음에서 108,000개 게임 경로를 조사했다. 첫 선택이 480회 후보의 콜과 이전 256회 추가 피팅 후보의 폴드로 갈린 7,782개 상황에서 양쪽 행동을 각각 실행했다. 이후 480회 정책·상대·카드를 고정해 15,564개 최종 손익을 재현했다.

| 상대 | 해당 상황 수 | 상황 1회당 콜 − 폴드 (BB) | 세 상대군 동시 95% 구간 |
| --- | ---: | ---: | ---: |
| 공개 | 2,595 | −2.26 | [−3.84, −0.67] |
| 혼합 | 2,796 | +9.78 | [+6.16, +13.41] |
| NoRegrets | 2,391 | +11.16 | [+4.63, +17.68] |

세 시드에서 방향이 일치했다. 이전 후보가 새로 폴드를 선택한 상황에서 폴드의 이득은 상대에 따라 달랐다. 이 수치는 선택이 갈린 상황 1회당 손익이며 504회 후보의 성능은 아래 별도 평가에서 판단한다. 포지션·콜 비용·팟 오즈로 묶은 모든 관측 집단에 기존 학습 표본이 있었다. 이 집계만으로 각 손패의 학습 표적이 정확했는지는 알 수 없다. [행동별 손익과 표본 분포](../reports/preflop-followup/480-v1/call-fold-diagnosis/summary.json)

## 학습과 복구본

11월 19일 16:56 KST에 세 시드 모두 504회 학습을 끝냈다. 시드마다 자기대전 24회·6,144회 순회·포스트플롭 18,432회 업데이트를 실행했다. 회차마다 새로 수집한 표본의 합은 시드 342·343·344 순서로 186,398·193,026·201,605개였다. 전체 581,029개가 기존 상한을 둔 표본 저장소에 순차적으로 들어왔다. 각 시드는 486·492·498·504회에 저장했고, 24회 모두 포스트플롭 가중치가 갱신됐다. 프리플롭은 첫 행동을 포함해 회차별 265개 상황에서 출발 확률과 일치했고 최종 파일도 원본과 바이트 단위로 일치했다. 보조 평균 모델의 TV 오차는 0.17888·0.16187·0.16432로 참조값 0.15를 넘었다. 사전에 정한 대로 6인 대전 성능은 주 정책을 평가했다. [학습 검증](../reports/preflop-followup/480-v1/fixed-preflop-504/training-verification.json)

16:59 KST에 504회 학습 복구본 107,389,967바이트를 비공개 Drive 인덱스에 기록했다. 파일 92개를 추출해 세 시드의 가중치·표본·난수 상태와 네 스트리트의 행동을 대조했다. 2개 조각을 로컬에서 재결합한 SHA-256이 원본과 일치했다. Drive에서 두 조각과 복원 목록의 원격 크기와 소유자 전용 권한을 확인했다. 원격 체크섬은 제공되지 않았다. 관리 용량은 1,738,191,709바이트(1.62 GiB)다. 최종 평가 기록은 별도로 보관한다.
