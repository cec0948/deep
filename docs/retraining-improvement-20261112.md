# 120회 성능 하락 진단과 개선 실험

사용자는 성능 하락 이유와 잘못된 부분을 확인하고 개선 실험을 진행하도록 승인했다. 기존 120회 checkpoint와 비공개 백업은 보존한다. 기존 자동 연장 규칙의 수치 기준은 유지한다.

## 확인된 문제

1. 평가 시작 seed만 달리하고 실제 카드 범위의 중복을 검사하지 않았다. 평가기는 `시작 seed + deal 번호`를 사용한다. 첫 구간 2026111201~2026113200과 두 번째 구간 2026111203~2026113202는 1,998/2,000개의 카드 seed를 공유한다. 이전 문서의 독립된 새 카드라는 설명을 정정한다. 구간 내 같은 카드로 비교한 점수 차이는 유효하지만, 구간 간 카드 독립성을 주장할 수 없다. 연장 시 전체 카드 범위만큼 이동하고 중복 범위를 거부하도록 수정한다.
2. 첫 행동 신경망만 TV≤0.10 검사와 추가 fitting을 적용한다. 나머지 상황을 맡는 main 신경망은 매 반복 재초기화한 뒤 1,024 steps로 학습하며 별도 적합도 검사가 없다. 진단에서 첫 행동을 제외한 unraised-preflop 상태의 경험적 평균 표적과 정책 차이가 컸다. 이것이 성능 하락의 원인인지는 아래 실험으로 분리해 확인한다.
3. 120회 현재 정책은 과거 정책 전체를 섞은 전략보다 혼합·NoRegrets 상대 성적이 크게 낮았다. 평가 상대 중 NoRegrets의 후반 스트리트 fallback 비율이 높으므로, 이 고정 상대만으로 일반적인 포커 실력을 판단하지 않는다.

## 결과를 보기 전에 고정한 실험

- 부모: `artifacts/compact-v4/20261112T032318825281Z`, 세 seed 342·343·344 모두 사용.
- 후보: 기존 120회 main 신경망을 동일한 고정 replay로 3,072 steps 추가 fitting. 첫 행동 전문가·스케일·표본·자기 대전 회차는 보존한다. 새로 180회 학습한 결과로 표시하지 않는다.
- 비교: 현재 120회 정책, 전체 시간 혼합 120회, 추가 fitting 후보. 총 3정책×3seed×3상대 = 27셀, 각 2,000 deals×6좌석 = 324,000핸드.
- 평가 카드: `2026120000~2026121999`. 이전 본 평가 범위와 겹치지 않는다. 각 셀은 같은 카드 묶음을 사용한다.
- CPU 단일 thread 작업 최대 3개. 기존 캠페인의 registry나 controller를 재실행하지 않는다.
- 후보별 현재120 대비 공통 deal-block 개선량을 계산한다. 기존 네 조건(공개 하한>0, 공개 개선 seed≥2, 혼합 하한≥−25, NoRegrets 하한≥−50)을 그대로 표시한다. 두 후보를 보는 탐색 실험이며 자동 배포·승격은 하지 않는다. 이후 채택에는 별도 독립 검증이 필요하다.

설정은 `configs/compact-refit-probe-20261112.json`에 고정하며, 실행 전에 복사한 설정과 소스 해시를 보존한다. 결과와 실패를 모두 기록하고 새 후보 파일은 비공개로 백업한다.
