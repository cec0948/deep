# 리버 콜 가중치 후속 학습

이번 후보는 11월 27일에 채택한 리버 정책보다 검증 수익이 낮았다. 독립 카드 105,819핸드에서 얻은 대상 결정 2,304개에서 평균 차이는 결정당 **−0.048 bb**였고 95% 구간은 **−0.083~−0.013 bb**였다. 해당 결정이 없었던 핸드까지 포함한 이 변경의 평균 기여는 100핸드당 **−0.155 bb**였다. 실제 플레이에는 11월 27일 앞선 정책을 사용한다. 콜·폴드 확률이 달라진 160개 국면 중 153개에서 콜 확률이 높아졌다. 콜을 늘린 국면의 손익 기여는 두 상대의 각 시드, 총 여섯 조합에서 모두 음수였다. 이번 실험에서는 같은 25% 확률 조정 폭과 5%포인트 기준을 두 정책에 적용했으므로 이 차이는 새 점수 추정에서 비롯됐다.

기존 리버 모델의 절편과 계수에서 시작해 14번 갱신했다. 이전 학습용 결정 2,304개와 새 결정 1,536개를 썼다. 새 표본은 420회 정책과 팟의 3분의 1 또는 1.5배를 베팅하는 압박형 상대에게서 얻었다. 합법적인 베팅 한도를 적용했다. 팟이 큰 결정에 더 큰 비중을 주고, 카드 기준 승산이 베팅 가격·팟 크기·상대의 이전 레이즈와 함께 미치는 효과를 학습했다. 훈련 목적함수는 0.51813에서 0.51261로 감소했다. 검증 카드는 새로 나눠 줬다. 상대는 앞선 실험의 검증에도 사용한 두 정책이며, 이번 학습 자료에는 포함하지 않았다. 프리플롭부터 두 상대의 실제 행동을 재생하고 각 리버의 콜·폴드 종결 손익을 규칙 엔진으로 다시 확인했다. 세 시드의 일반 게임 입력 18개로 최종 실행 경로를 검증했다.
