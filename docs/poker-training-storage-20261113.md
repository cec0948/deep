## 복구 범위와 이후 보관 원칙

이 복구본은 최신 정책과 기존 경험을 이용하는 별도 추가 학습의 재료다. 과거240개 정책/seed를 확률적으로 섞던 평균 정책과 옛 worker의 정확한 `--resume`은 지원하지 않는다. `resumable_selfplay=false`, `exact_legacy_resume=false`, `warm_start_state_verified=true`, `historical_mixture_available=false`로 구분한다. 기존 전체 백업의 부재를 학습 실패나 파일 유실로 표시하면 안 된다.

복원은 `scripts/compact_lightweight_backup.py restore ARCHIVE --destination NEW_EMPTY_DIRECTORY`로 수행한다. archive 안의 `restore_lightweight.py`도 같은 기능을 제공한다. `load_state(DIRECTORY/seed-N)`은 네트워크·replay·첫 행동 통계·난수 상태를 반환한다. 복원은 학습을 시작하지 않으며 `latest.pt`를 생성하지 않는다. 원본 registry를 덮어쓰거나 옛 controller에 전달하면 안 된다. 새로운 학습에는 별도로 고정한 계획과 실행 경로가 필요하다.

앞으로 같은 모델 구조·표본 상한을 사용하는 백업은 최신 정책만 보존하고 과거 정책 파일을 누적하지 않는다. 표본은좌석당100,000개·모델당600,000개로 제한한다. 새 exporter는 진단 로그도 마지막60회로 제한한다. 데이터 내용에 따라 압축률은 달라질 수 있지만 백업에서 대용량 모델 이력과 표본 개수가 학습 회차에 비례해 늘어나는 구조를 제거한다. 최신 복구본을 완전히 검증한 뒤 이전 복구본을 교체하며, 필수 기준본과 연구 의존성·2GiB 목표는 유지한다.

`artifacts/offsite-backups.json`의 새 기록은 기존240회 전체 archive의 SHA-256을 `source_archive_sha256`으로 식별한다. `stage-240-backup.json`은 당시 전체 archive 생성 증거로 그대로 두었다. 새 경량 기록이 동일240회 상태를 이미 보존하고 있으므로, 삭제된 원격 전체 archive를 새 진도로 오인해 다시 업로드하면 안 된다.

## 현재 학습 표본을 만드는 과정

1. 52장을 무작위로 섞고 dealer를 바꾸어6인 자기대전을 시작한다. 현재 설정은 시작 스택100BB 고정이며, 각 학습 seed의 현재 정책이 여섯 좌석의 행동을 결정한다. 공개 상대는 별도 평가에 사용한다.
2. 한 회차에 학습할 좌석 하나를 선택하고256개 탐색을 시작한다. 좌석은6회에 걸쳐 순환한다. 그 좌석의 합법 행동을 모두 분기하고 다른 좌석의 행동은 현재 정책에서 확률적으로 뽑는다. 한 탐색에서 여러 분기를 만들기 때문에256탐색은256개 완성 핸드나256개 표본과 같지 않다.
3. 각 분기의 마지막 손익을 계산한다. 한 상황에서 행동별 추정 손익과 현재 전략의 평균 손익의 차이를 regret 표본으로 만든다. 예를 들어 레이즈의 추정값이+5BB이고 현재 전략 평균이+2BB라면 그 행동의 상대적 학습값은+3BB다. 이것은 상대 행동을 표본 추출한 추정치이므로 반복 표본의 잡음이 있다.
4. 자기 패·공개 보드·팟·스택·좌석·베팅 상태·합법 행동을51개 숫자로 요약하고,5개 행동의 상대적 손익차·수집 회차와 함께 저장한다. 좌석마다 reservoir buffer 최대100,000행을 보관한다. 상한 이후에는 새 경험을 확률적으로 받아 기존 행을 교체한다. 최근 것만 남기는 FIFO가 아니라 과거 경험도 일부 남기는 방식이다. 모델3개가 각각6개 버퍼를 가지므로 현재 보관량은총180만 행이다.
5. 첫 행동의 표본이 부족하지 않도록169개 시작 패 유형을 별도로 반복 시뮬레이션한다. 이 표본은 유형별 가중 합과 개수 등 작은 충분 통계로 모은다. 보통 회차당 유형별4회이며 처음부터 시작한 첫 회차만16회다.
6. 직전 모델은 새 표본을 수집하는 정책으로 쓰고, 현재 구현은 회차마다 regret 회귀망을 새로 초기화해 보관 표본으로 다시 맞춘다. batch512·주 학습1,024steps이며 상황별 sampling/scaling과 첫 행동 fitting을 별도로 사용한다. 따라서 단순히 최신 가중치에 새 승패 기록만 계속 추가하는 구현은 아니다.

이 표본은 무작위 자기대전에서 얻은 행동별 손익 추정이다. 실제 사람의 정답 행동이나 강한 공개 상대의 답을 복사한 자료가 아니다. 기존51차원 특징에는 일부 행동 이력·카드 무늬 관계를 잃는 한계가 확인돼 있으며, 입력 변경 실험에는 원래 상태를 보존하는 별도 표본 수집이 필요하다. 이번 작업은 저장 형식 변경이며 이 학습 방법이나 평가 조건을 바꾸지 않았다.
