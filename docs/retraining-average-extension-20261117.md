# 420회에서480회까지 같은 설정으로 추가 자기대전

2026-11-17 사용자는420회 결과와 불확실성의 의미를 확인한 뒤 “계속 또 학습 진행 해주세요”라고 요청했다. 완료된420회 실행 `20261117T032100Z`를 보존하고, 새 실행에서 세seed 모두420→480회로60회를 추가한다. 유한한 평균 근사 오차나 중간 성적만으로 주 학습을 중단하지 않는다. 자동 알림은 사용자 요청대로 꺼진 상태를 유지한다.

## 변경 없이 이어받는 학습

주 모델 가중치, 좌석별replay, 첫 행동 누적 통계, 네 종류 학습 난수 상태, 별도 평균 표본과 수집 난수 상태를 그대로 복원한다. 초기 모델이나 고정replay 추가 fitting으로 시작하는 실험이 아니다. 기존 학습 kernel을 직접 재사용하며 회차당256traversals,1,024steps×batch512,학습률0.001,좌석당100,000행을 유지한다. 이전 실행의 가중치 정규화 상수420도 유지한다. 표본 상한은 주replay3seed합계1,800,000행과 평균replay300,000행이다.

평균 수집 자료를 초기화하지 않아 보조 평균의 구간은361~480이다.128폭·8,192steps×batch512 설정으로480회에만 다시 fitting한다. 이는 전체1~480회 역사 평균이 아니고, 근사TV≤0.15는 진단으로 계속 공개한다. 유한한 오차 미달을 실력 악화나 주 학습 실패로 간주하지 않는다. 실제 행동의 수치 오류, 비유한값, 출처·상태 불일치, 실행 오류, 기존 주 모델의 fitting 품질 실패는 중단한다. 자동 재시도·모델 교체·480회 이후 연장은 없다.

새 registry는 `artifacts/average-extension/current.json`, 감독은 `run_poker_average_extension.py`, 학습기는 `train_poker_average_extension.py`, 평가기는 기존 `evaluate_average_baseline.py`다. 이전420회 registry와 보고서는 보존한다. 세 학습worker를 각단일thread로 실행하고, 모두 종료한 뒤 세 평가기를 병렬 실행한다. 각 학습worker90분·평가셀40분·전체6시간의 고정 상한이다.

## 시작 전 확인

완료된420회 복구 archive99,711,994 bytes의 로컬SHA·실제 추출·수치 복원을 확인한다. 새 경로에 옮긴 주/평균 모델·표본·첫 행동·난수 상태가 세seed 모두 byte 일치해야 한다. 실제420회 상태에서 다음421회 전체 업데이트를 기존 동결 학습기와 비교하고, 평균 자료 수집이 주 학습 난수 흐름을 변경하지 않는지 확인한다. 사전검사용20카드2037380000~2037380019×6좌석×3상대=360핸드는 신뢰 엔진으로 실제 행동을 재현하며 실력 평가에 사용하지 않는다.

## 고정 평가

새20,000개 카드 묶음2037400000~2037419999에서 원본120회·부모420회·최신480회·평균361~480의4정책×3고정seed×3상대=36셀·4,320,000핸드를 평가한다. 이전 평가와 카드 구간이 겹치지 않아야 한다. 실제 행동을 신뢰 엔진에서 재현한 뒤 성적을 확정한다. 통계 단위는20,000개 카드 묶음이며 좌석과seed는 묶음 안에서 평균한다.

주 후보는 최신480회다. 원본120회 대비 기존 네 채택 조건을 그대로 보고하되, 이번 추가 학습의 변화는 **같은 새 카드에서480회−420회**로 별도 계산한다. 부모420·최신480·평균의3쌍×3상대에는9비교 동시95%구간을 보고한다. 주 후보를 결과를 보고 평균 모델로 바꾸지 않는다. 작은 양의 점수는 관측값으로 그대로 보고하고, 통계적 불확실성과 모델 채택 판단을 구분한다. 학습 완료와 전체36셀 평가 완료는 별도 상태다.

## 복구와 저장

480회 최신복구본 하나만 만들며 주/평균 모델·고정상한표본·모든난수·동결코드와 원본120/부모420 비교 가중치를 포함한다. 중간 저장은 시작420회와 최신 하나만 보존한다. 새archive의 실제 복원과 로컬SHA·크기·원격크기·소유자전용권한을 검증한 뒤에만 비공개 인덱스에 완료로 기록한다.100MiB초과이면64MiB이하 조각과 순서·크기·해시·DriveID 복원manifest를 쓰며 원본/재결합 로컬SHA가 일치해야 한다. 원격 체크섬이 없으면 원격 해시 검증을 주장하지 않는다.

`plan_average_extension_backup_retention.py`는 검증 완료된480회가 명시적으로 대체하는420회 archive만 정리 후보로 잡는다. 다른 활성 백업의 복원 의존성이 있으면420회도 보존한다. 원본360회·rich96회·첫60/필수120회·최근파생2개·최신연구·평가자산과 모든 의존성은 유지한다.2GiB 목표를 넘는 필수 백업은 삭제하지 않는다. 실제 삭제는 최신 계획·인덱스 불변·대상 원격 크기/권한 재검증 후에만 하고, 비공개journal·NOT_FOUND·deleted_remote를 남긴다. 현재420회까지의 검증된 보관량은약1.21GiB이고, 새480회 검증 전 기존복구본을 지우지 않는다.

학습 시점 archive에는 뒤에 수행할 최종평가가 포함되지 않는다. 상태·계획·사전검증·최종결과는 `reports/average-extension-status.json`과 `reports/average-extension/<run>/`에 게시한다. 종료 후 결과를 확인하기 전에는 성능 향상을 주장하지 않는다.
