## NoRegrets

- https://github.com/conorarmstrong/noregrets
- 검토 커밋: `757f7692738069522195d2b486eec60a8b010c0c`
- 공개 코드: MIT. README는 공개 버전이 비공개 개발 버전보다 약 12개월 늦으며 학습 모델은 공개하지 않는다고 설명한다.
- 상용 제안: 최신 소스, 학습된 blueprint, 통합 지원. 이는 판매자의 설명이며 구매 가능 여부·가격·정확한 허용 범위는 확인 전이다.
- 외부 DB 없이 전략 파일을 생성하고 CLI에서 읽을 수 있다. 공개 CLI에는 별도의 JSON 의사결정 API가 없어 프로그램 연동용 어댑터는 추가 검토가 필요하다.
- `BASELINES.md`는 6인 학습, baseline 대전, 탐색의 성공/실패와 모델 해시를 기록한다.
- 공개 README의 HU Slumbot 대전은 blueprint만 -714.5 ±331.5 mbb/hand, search 포함 -1771.0 ±471.8 mbb/hand이다. 독립적인 강도 인증이 아니며 공개 버전의 상당한 한계를 보여준다. 상용 버전이 더 강하다는 가정도 검증 전이다.
- 짧은 로컬 실행은 학습/저장/복원/6인 대전의 기능 검사다. 프로급 실력 평가는 아니다.
- 이번 실행에서 release 빌드, 규칙 검사 13개, 체크포인트 검사 1개, 6인·100BB 학습→별도 프로세스 재개→200핸드 실행이 성공했다. 자세한 기록은 `noregrets-assessment.md`에 있다.

## CFR-NLHE-6max

- https://github.com/dberweger2017/CFR-NLHE-6max
- 검토 커밋: `ae4d3b978573faf3188b4e0a386196cc7ef2da80`
- `readme.md`는 저장소 이름이 역사적 이름이며 6인이 후속 목표임을 명시한다.
- MIT인 상위 코드와 달리 pinned `pokers` 의존성의 원 저작자 라이선스가 해결되지 않았다고 자체 감사에 기재되어 있다. 자체 배포에 채택하기 전에 확인이 필요하다.
- 이름만 보고 6인 공개 가중치가 있다고 판단하지 않는다. 이번에는 의존성 설치나 수 GB 모델 다운로드를 실행하지 않았다.
