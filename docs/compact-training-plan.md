# 작은 신경망 방식의 다음 검증·학습

2026-11-10. 사용자 요청대로 Deep CFR 계열의 작은 신경망 방식을 계속 사용한다. 목표는 6인·100BB, 집의 RAM 32GB와 일반 데스크톱 CPU에서 실행하는 정책이다.

## 수정 근거와 범위

고정 스케일 및 상태별 정규화를 비교했지만 첫 행동의 전략 오차가 이전 기준 TV≤0.10을 통과하지 못했다. 같은 망에 첫 행동만 학습시키면 표적을 맞출 수 있다는 이전 용량 진단을 바탕으로 **첫 UTG 행동과 나머지 상황을 별도 신경망으로 학습하는 후보**를 비교한다. 특정 패의 행동을 강제하는 규칙은 없다. 첫 행동 판정은 스트리트·위치·팟·남은 플레이어 수를 사용한다.

두 regret 전문가의 합계 파일은 약 1.18MB다. 플레이에서는 상황에 맞는 전문가 하나만 실행한다. 학습 표적은 원래 BB 단위로 보존하고, 한 입력 그룹의 모든 반복에 같은 양의 스케일을 적용한다. 샘플마다 평균을 빼거나 표준편차로 나누지 않는다.

모든 비교는 같은 세 V3 버퍼와 초기화 짝에서 수행한다. 기존 TV·AA·전체/스트리트 MSE 기준을 유지한다. 전문가 후보는 고정 버퍼에서 그 기준을 통과했으며, 같은 구성과 아래 root 수집기를 작은 게임의 학습 전체 검사에 연결한다. 완전한 6인 수렴 보장을 의미하지 않는다.

## 표적 수집

169개 UTG 패 종류마다 같은 횟수로 나머지 카드와 보드를 조건부 추출한다. 합법적인 첫 행동을 모두 평가하고 이후에는 모든 플레이어가 현재 신경망 정책으로 행동한다. 이 표본은 해당 행동의 조건부 기대 수익의 Monte Carlo 추정이다. 후속 노드의 regret 표본으로 재사용하지 않는다.

각 반복의 표본은 `t / 반복 내 표본 수`로 누적한다. 표본 수를 첫 회 16개, 이후 4개로 바꿔도 원하는 시간 평균은 변하지 않는다. 첫 행동의 충분통계는 일반 reservoir에서 퇴출되지 않으며, 동일 입력의 일반 regret 표본은 그 대신 학습에 중복 포함하지 않는다. 작은 비균등 전략 게임의 가능한 표본 경로를 열거해 추정량을 검증하고, RNG·모델·두 replay를 함께 저장한다.

이 장치는 학습용이다. 플레이 시에는 학습 자료나 큰 전략표를 조회하지 않는다.

## 평균 전략

현재 평균 전략 collector의 큰 중요도 가중치와 평균 신경망의 근사 문제를 피하기 위해 **매 반복에서 실제 사용한 정책을 전부 저장**한다. 반복 t의 업데이트 **직전** 정책 sigma^t를 가중치 t로 기록한다. 핸드 시작 시 독립적인 hand_seed로 정책 하나를 뽑고 그 핸드가 끝날 때까지 유지한다.

이는 [SD-CFR](https://arxiv.org/abs/1901.07621) 계열의 정책 혼합 방식이다. 완전기억 게임에서 이러한 혼합은 own-reach 가중 평균 행동 전략과 같은 행동 분포를 만든다. 매 행동마다 다시 정책을 뽑거나, 카드로 정책 선택 seed를 만들면 이 성질을 사용할 수 없다. 수치 fixture에서 후속 정보집합의 own-reach 평균과 대전 기대값을 비교하고, 첫 정책·매 회차·가중치·재개를 검사한다.

60개 정책의 파일 총량은 약 71MB이며, 각 행동에서 전부 추론하지 않는다. 현재 정책과 혼합 정책을 별도 후보로 평가한다. 51개 요약 특징과 6인 게임의 한계는 남는다.

## 제한된 새 학습

[고정 설정](../configs/fullhouse-compact-training.json)을 실험 전에 저장한다. 고정 버퍼와 Kuhn 세 seed, 배포 수치 검사와 정확 재개 검사를 통과해야 실행한다.

- seed 342·343·344, 새 모델·빈 버퍼, 60회, 12·30·60회 상태 확인.
- 반복당 원래 external traversal 256개, main fitting 1,024×512. 첫 행동 fitting은 2,048회에서 시작해 필요 시 최대 8,192회까지 수행한다.
- 첫 행동은 첫 회 패 종류당 16개, 이후 반복당 4개. 60회 완료 시 각 종류 252개 관측을 보존한다. 초기화·학습·평가 seed를 구분한다.
- 평균 신경망을 별도 학습하지 않고 전체 pre-update 정책 혼합을 보존한다.
- 새 deal seed 170261110, 셀당 2,000 deals×6좌석. 30회는 두 기존 상대 풀, 60회는 혼합 풀까지 평가한다. 공개 모델과 기존 V3 advantage도 같은 카드로 다시 평가한다.
- 30→60의 paired 차이와 모든 학습 seed를 보고한다. 고른 최고 seed의 점추정만으로 승격하지 않는다.

모든 실행은 현재 CPU 환경에서 한다. 평가·학습 결과가 기준을 통과했다는 사실과 프로급 실력은 구분한다.
