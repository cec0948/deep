# V3 엔진 수정 후 3-seed 재학습 결과

2026-11-09. **엔진 수정, 평균 전략 fitting 안정화, 새 버퍼에서 seed 42·43·44 각각 120회 학습, 288,000핸드 평가를 완료했다.** 기존 평균 전략보다 개선됐지만, 60→120회 추가 학습의 일관된 이득은 확인하지 못했다. 같은 학습의 최종 advantage 정책이 평균 전략보다 강했다. 프로급 성능은 검증하지 않았다.

구현·사전 설정은 [V3 학습 문서](fullhouse-v3-training.md), 모든 후보의 결과·paired 계산·압축 원시 로그는 [실험 보고서](../reports/fullhouse-v3/20261109T034714104421Z/README.md)에 있다. 원시 288,000핸드에서 deal·좌석의 중복/누락, deck seed, 칩 보존, 손익과 신뢰구간을 다시 계산해 검산했다.

## 1. 무엇을 완료했는가

- 짧은 올인 뒤 추가 콜 누락, 한 명만 행동 가능한 상황의 runout, 3명 이상 동률의 odd chip 분배, 작은 opening all-in의 특징 불일치를 수정했다.
- 과거 반례 86개와 새 2,000핸드, 총 38,316상태를 독립 Rust 엔진과 비교했다. 최종 손익·51개 특징·합법 동작도 확인했다. 기존/V3 회귀 검사 25개와 이후 추가한 독립 사이드팟/runout 검사 1개가 통과했다.
- 평균 전략에 입력 특징별 그룹 추출, 그룹 내부 중요도 비례 추출, batch 512, 512 optimizer steps, 후반 파라미터 평균(SWA)을 적용했다. 동일 입력의 경험적 조건부 평균은 보존하되 유한한 공유 신경망의 상태별 투영 가중치는 바꿨다.
- 세 seed 모두 과거 모델·버퍼를 이어 쓰지 않고 빈 버퍼에서 시작했다. 단일 CPU의 연속 실행·분할 재개·같은 seed 재실행이 모델·버퍼·RNG까지 정확히 일치했다. V2 checkpoint 재개는 거절한다.
- 소스·모델·평가기·엔진 해시를 고정하고, 12회 간격 전체 checkpoint와 세 seed의 별도 60회 전체 버퍼를 보존했다.

실행은 `artifacts/fullhouse-v3/20261109T034714104421Z/`다. 4 vCPU 한도 환경에서 단일 worker/thread 세 개를 병렬 사용했다. 학습 프로세스별 누적 구간 시간은 47.16·51.15·47.07분이며, 전체 학습과 평가의 경과 시간은 약 65분이다. GPU·유료 서버는 사용하지 않았다.

## 3. 60회보다 120회가 항상 강해졌는가

그렇지 않았다. 같은 seed의 평균 전략 `120 − 60` 차이다.

| 학습 seed | NoRegrets 상대 | 공개 Fullhouse 상대 |
| --- | ---: | ---: |
| 42 | +49.55 ±88.87 | +24.62 ±42.68 |
| 43 | -105.38 ±87.30 | -24.79 ±41.81 |
| 44 | -23.13 ±105.07 | -44.30 ±41.92 |

세 모델을 deal별로 먼저 평균하면 -26.32±59.14, -14.82±24.05로 모두 0을 포함한다. seed 43/NoRegrets와 seed 44/공개 상대에서는 개별 명목 구간이 하락 방향으로 0을 제외한다. 여러 비교에 대한 동시 신뢰구간은 아니므로 그 두 결과만으로 보편적 후퇴를 선언하지 않는다. **현재 설정의 단순 연장을 정당화할 일관된 학습 곡선 개선은 없다.** 이번에는 120회에서 종료했고 600회나 유료 규모로 확대하지 않았다.

## 4. 해결된 문제와 남은 문제

새 최종 버퍼에서 UTG 169개 입력의 조건부 평균과 평균 전략 네트워크 사이 가중 TV 오차는 seed별 **0.05459, 0.05186, 0.04613**이다. AA의 버퍼 표적 대비 레이즈 확률 오차도 약 5.4·5.4·6.7%p다. 이전 고정 버퍼의 AA 레이즈 표적 68.14%를 16.76%만 출력하던 큰 불일치는 새 fitting 방식에서 줄었다. 이 표적이 포커 최적 전략이라는 뜻은 아니다.

그러나 전체 중요도 collector의 분산은 해결하지 않았다. 최종 strategy buffer는 seed별 200,000행이며:

| 학습 seed | 가중치 ESS | 상위 1%의 원래 가중치 점유율 |
| --- | ---: | ---: |
| 42 | 11.09 | 93.02% |
| 43 | 32.31 | 91.16% |
| 44 | 38.50 | 92.29% |

ESS는 집중도 지표이며 독립 표본 수가 아니다. 그룹 재가중은 이 큰 가중치가 다른 상태 그룹까지 지배하는 것을 줄이지만, 그룹 안의 희귀 관측 집중을 없애지는 않는다. 그룹별 진단과 전체 replay의 행별 KL은 각 seed의 `fit-00060.json`, `fit-00120.json`에 있다. 버퍼가 달라지고 행별 표적 자체의 불일치도 포함되므로 이 손실 수치를 60→120의 동일 데이터 fitting 비교로 해석하지 않는다.

공개 상대에서 최종 average는 같은 seed의 advantage보다 **176~229 BB/100 낮았고**, 세 paired 구간 모두 0을 제외했다. 따라서 현재 실사용 후보로는 advantage 쪽이 더 유망하다. 다만 이 차이만으로 원인을 평균 신경망 fitting 하나에 귀속할 수는 없다. 과거 정책의 평균 자체, collector 추정 분산, 상태 요약/네트워크 근사가 함께 영향을 준다. 엔진·추출 방식·fitting 예산·SWA를 함께 바꿨으므로 각각의 기여량도 분리하지 못했다.

최종 JSONL 실행 검사에서 **advantage의 regret fitting에도 남은 오류**를 직접 확인했다. UTG에서 AA를 처음 받았을 때 seed 42는 29.25%, seed 43은 25%를 폴드한다. Torch 학습 네트워크와 npz 배포 네트워크를 세 seed에서 비교해 같은 확률이 나오는 것을 확인했으므로 내보내기 오류는 아니다.

같은 51개 입력을 가진 regret replay 행을 직접 시간 가중 평균했다. 단위는 학습기의 BB regret이다.

| seed | 일치하는 replay 행 | 폴드 regret의 경험적 표적 | 신경망 예측 | 실제 폴드 확률 |
| --- | ---: | ---: | ---: | ---: |
| 42 | 18 | -73.85 | **+0.49** | **29.25%** |
| 43 | 14 | -30.76 | -3.39 | **25.00%** |
| 44 | 20 | -83.94 | -2.12 | 0.00% |

seed 42는 폴드 regret의 부호를 바꿔 예측했다. seed 43은 경험적 pot-raise 표적이 +10.63인데 -2.86으로 예측했고, 합법 동작 예측이 전부 0 이하가 되어 균등 fallback으로 AA를 25% 폴드했다. 표본 14~20개의 경험적 평균을 참 최적 전략으로 해석하지 않더라도 **자신의 저장 표적을 충분히 맞추지 못하는 사례**다. 원시 표적·입력·두 runtime의 출력은 [advantage-aa-audit.json](../reports/fullhouse-v3/20261109T034714104421Z/advantage-aa-audit.json)에 있다. 이 진단으로 모델을 다시 학습하거나 특정 핸드 규칙을 덧씌우지는 않았다.

따라서 다음 구현 우선순위에는 평균 전략뿐 아니라 **regret 네트워크의 적합도 보강**도 포함해야 한다. 현재 regret 신경망은 매 반복 재초기화하며 512×128=65,536개 예제를 추출해 학습한다. 더 큰 예산과 입력 상태별 균형을 새 고정 버퍼에서 비교해, AA 같은 드문 상태를 놓치는 문제와 표적 분산을 구분해야 한다.

## 5. 실행할 수 있는 모델과 다음 우선순위

현재 두 상대 풀에서 가장 높은 점추정은 **seed 42의 120회 advantage**다. 공개 모델 대비 paired 차이는 NoRegrets 상대 +175.80±92.99, 공개 상대 +1.50±30.39다. 후자는 우월성을 확인하지 못한 결과이며, 동등성이나 프로급 성능을 증명한 것도 아니다. 위 AA 폴드 문제와 최상위 seed 선택 편향도 있으므로 기본 모델을 자동 교체하지 않았다.

이 후보를 프로그램에서 명시적으로 호출하는 JSONL 실행 명령:

```bash
cd /workspace/deep
run_dir=artifacts/fullhouse-v3/20261109T034714104421Z
/workspace/.venvs/fullhouse/bin/python scripts/fullhouse_v3_runtime.py \
  --source "$run_dir/source" \
  --model "$run_dir/seed-42_adv/iter_00120.npz"
```

입력 형식은 [JSON API](json-api.md)를 따른다. 6명·전원 100BB 시작 조건이며, `scripts/run_poker.py --backend fullhouse`의 기존 공개 모델 기본값은 유지했다.

다음 우선순위는 **보존한 새 버퍼에서 regret fitting의 수치 반례를 개선하고, 후보 advantage를 새 deal seed와 더 다양한 상대에 검증하는 것**이다. 평균 전략 쪽은 postflop 그룹의 조건부 표적과 fitting 변동성을 분리한 뒤 collector를 개선한다. snapshot 정책 혼합(SDCFR 계열)도 평균 신경망을 대신할 후보지만, 현재 저장된 12회 간격 모델만으로 기존 collector의 정확한 전체 시간 평균을 복원했다고 주장할 수 없다. 전체 반복의 정책 저장·한 핸드 안의 정책 유지·작은 게임의 기준 평균과 비교하는 별도 검증이 필요하다. 6인 수렴과 요약 특징의 imperfect recall은 여전히 이론적 제한이다.
