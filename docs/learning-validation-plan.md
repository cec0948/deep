# 학습 확대 전 검증 기준

2026-11-09. V3의 AA regret 예측 오류 이후, 학습기 검증을 성능 확대보다 먼저 수행한다.
실험 전에 저장한 [설정](../configs/fullhouse-learning-validation.json)을 실행 폴더와 보고서에 복사하고 SHA-256을 기록한다. 결과를 본 뒤 같은 실행의 통과 기준을 낮추지 않는다.

## 고정 버퍼 적합도

V3 120회의 seed 42·43·44 체크포인트는 수정하지 않는다. 각 버퍼를 초기화 seed 7·8·9와 사전에 짝지어 아래 세 설정을 비교한다. 입력과 시간 가중 표적은 동일하다.

- 기준: 현재 `train_network`, 512 steps × batch 128.
- 예산 확대: 같은 함수, 2,048/8,192 steps × batch 512. 최종 8,192만 채택 후보.
- 상태 균형: 22개 이하의 위치/스트리트/팟 크기 그룹에 같은 확률을 부여하고 그룹 안에서 시간 가중치에 비례해 추출한다. unopened preflop의 완전히 동일한 51개 입력은 가중 평균 표적으로 합친다. 각 입력의 조건부 평균은 보존하지만, 전체 유한 신경망의 투영 가중치는 변경한다. 2,048/8,192 steps × batch 512.

AA의 특정 행동을 강제하는 규칙은 없다. 동일 입력의 원시 표적을 직접 평균한 값이 기준이다. 이는 유한한 Monte Carlo 경험 표적이며 최적 포커 전략이라고 간주하지 않는다.

통과는 세 짝 모두에서 UTG 전체 입력의 시간 가중 TV ≤0.10, AA 폴드 ≤0.01(경험적 표적에서도 폴드가 0이어야 함), 전체 MSE가 기준의 1.05배 이하, 네 스트리트 각각의 MSE가 기준의 1.10배 이하다. AA만 고친 채 다른 상황을 악화시키는 설정은 채택하지 않는다.

이 실험은 **저장된 데이터에 대한 in-sample 적합도**다. 데이터의 정확성·일반화·실력 증명과 다르다. 버퍼 seed와 초기화 seed의 영향을 분리하는 factorial 실험도 아니다.

## 작은 게임의 학습 전체 검사

Kuhn poker의 전체 12개 정보집합을 손실 없이 인코딩한다. 각 플레이어의 64개 결정적 전략을 전수 조사해 best response를 계산한다. 상대 카드에 따라 행동을 바꾸는 잘못된 완전정보 best response를 허용하지 않는다. 알려진 균형의 값 -1/18 ante, exploitability 0과 독립적인 표 기반 CFR을 대조한다.

학습기는 V3의 `traverse_external`, `ReservoirBuffer`, `DuelingAdvantageNet`, `train_network`, importance 평균 수집기, 평균 신경망 및 V3 fitting을 재사용한다. 게임 규칙과 입력 인코더만 Kuhn용으로 교체한다. 별도로 균등 정책의 모든 무작위 경로를 열거하여 실제 traversal의 regret과 손계산을 비교한다.

seed 71·72·73, 120회, 회당 순회 256개와 regret fitting 256×128. 평균 신경망은 자기 대전의 행동을 결정하지 않으므로 12·60·120회 측정 시점에 512×512로 학습한다. 매 반복의 실제 정책을 정확히 own-reach 평균한 값, 수집 버퍼 평균, 신경망 평균을 각각 기록해 오차 발생 위치를 구분한다.

최종 신경망 exploitability는 ante/hand 단위로 0.05 이하이며 초기 균등 정책의 절반 이하여야 한다. 전체 정보집합에서 정확 평균 대비 collector TV ≤0.05, 버퍼 평균 대비 신경망 TV ≤0.03, 표 기반 기준 exploitability ≤0.005를 요구한다. 세 seed가 모두 통과해야 한다.

Kuhn 통과는 2인 완전기억 검사다. 6인 수렴이나 실제 포커의 요약 특징을 검증한 것으로 표현하지 않는다. 예산 확대 방식은 먼저 Kuhn에서 검사한다. 상태 균형 방식으로 6인 단계에 가려면 같은 방식의 Kuhn 검사도 통과해야 한다. 고정 버퍼 실패 후에도 원인을 구분하기 위해 상태 균형 방식의 Kuhn 검사를 별도 진단으로 수행했으며, 설정과 기준은 동일하게 유지했다.

## 6인 단계의 조건

같은 후보 방식이 고정 버퍼와 작은 게임의 기준을 모두 통과해야 제한된 새 6인 학습·새 deal seed 대전을 진행한다. 실패하면 해당 검사와 원인을 보고하고, 같은 설정의 장기 학습을 시작하지 않는다. 과거 모델의 기본값을 자동 교체하지 않는다. 유료 서버나 GPU는 이번 검증에 사용하지 않는다.

실험 코드와 통과 기준, 실패한 결과도 Git에 보존한다. 실행 모델과 원래 replay는 `artifacts/`에 남긴다.
