# 원본120회 이후 자기 대전과 확대 평가

사용자는 2026-11-12 평가 카드 수를10배로 늘리고 학습 방법에 문제가 있는지 확인한 뒤 계속 진행하도록 승인했다. 이에 따라 원본120회 복구본에서 새로운 자기 대전 표본을 만드는 별도 고정 예산 연구를 준비한다. 최근의 고정 replay fitting 실험을 반복하는 것이 아니다.

## 질문과 사전 계획

120회는 충분성이나 수렴이 입증된 지점이 아니다. 기존 설정의1회는6좌석 중 한 좌석을 번갈아 갱신하는256traversals이며,120회는 seed별30,720개 traversal 시작과 좌석당20번의 표본 수집 갱신이다. 원래60→120회는 공개 상대에+41.12bb/100 개선됐고, 혼합·NoRegrets 보존 조건 미달로 자동 연장이 멈췄다. 이후의 replay fitting 실패만으로 추가 자기 대전의 효과를 결론낼 수 없다.

이번에는 원본120회 `20261112T032318825281Z`의 세 seed342·343·344를 복사하고 **180회와240회**까지 새 자기 대전을 진행한다. 신경망·버퍼·root replay·난수 상태·정책 이력을 그대로 이어받고, 원본 파일과 기존 controller·registry는 유지한다. 기존 입력·학습률·표본 비중·fitting 예산은 고정하며 실패한 raw-objective 보정을 적용하지 않는다.

학습을 시작하기 전에 동결 소스, traversal/합법 행동/손익 처리, 실제 replay·정책 이력, 재개 동치와 배포 평가를 점검한다. `reports/continuation-study/method-audit-20261112.json`의 완료·차단 오류 없음·검사 통과 및 소스 해시가 확인돼야 실행한다. 이는 방법에 아무 한계도 없다는 선언이 아니다.51차원 입력의 정보 손실, 상황별 균등 sampling과 scaling에 따른 경험적 손실 변경,6인 공유망의 근사 등은 이미 알려진 한계이며 추가 표본만으로 해결된다고 보장하지 않는다.

## 카드 수와 판정

- 이전 평가의2,000개 대신 **새 카드20,000개**, seed범위2026160000~2026179999를 고정한다. 기존 모든 기록과 범위 비중복을 확인한다.
- 원본120회·180회·240회의 최신 정책과 snapshot 평균 정책을 모두 평가한다. 상대 구성은 기존 공개·혼합·NoRegrets3종이다.
- `3시점 × 2정책 × 3학습seed × 3상대 × 20,000카드 × 6좌석 = 6,480,000핸드`, 총54개 평가 셀이다.
- 상대 하나에서 정책 하나의 세 seed 합계는360,000핸드다. 통계 계산의 기본 독립 단위는20,000개 카드 묶음이며, 좌석·학습seed·정책별 반복을 독립 표본으로 부풀리지 않는다.
- 같은 새 카드 묶음을 고정된 세 시점에 공유해 paired 차이를 계산한다.180회와240회를 독립된 최종 holdout이라고 부르지 않으며 반복 연구에 대한 다중검정 보정도 주장하지 않는다.
- 기존 네 성능 조건은 후보 채택 검토에 그대로 사용한다. 각 시점의 최신·평균 정책 모두 원본 current120과 비교하며, 동종 정책의120→180→240 변화와 시점별 평균−최신 차이는 별도 진단이다.

이번에 승인한 **고정 연구 예산의 진행 여부와 후보 채택 여부를 구분**한다.180회의 성능 조건 미달만으로240회 관찰을 생략하지 않는다. 이는 기존 자동 controller의 기준을 바꾸는 것이 아니라 새로 승인한 학습 곡선 연구이며 기존 `artifacts/retraining-loop.json`은 분석 대기로 유지한다. 실행 오류·비유한 값·출처 불일치·기존 opening fitting 품질 실패가 있으면 중단하고 자동 재실행하지 않는다.240회에서 연구를 종료하며 기준 통과도 자동 모델 교체를 뜻하지 않는다.

## 실행·진행 기록·백업

새 실행은 `artifacts/continuation-study/current.json`과 해당 `status.json`·`evaluation-status.json`·`evaluation-summary.json`으로 추적한다. 공개 기록은 `reports/continuation-study-status.json`이다. 실제 실행은 PID·시작 토큰·명령행을 함께 확인한다. 원본 `artifacts/compact-v4/current.json`과 이전 probe·foundation 연구 registry를 새 실행으로 덮어쓰지 않는다.

현재 클라우드4vCPU에서 학습 worker3개와 평가1개를 병행하고 학습 종료 후 평가를 최대3개 병행한다. 기존 실측으로 추가120회 학습만 약60~80분 예상이며, 카드 수를10배로 늘린 평가에는 추가 시간이 필요하다. 전체 실행 상한은4시간, 학습 단계별90분, 평가 셀별40분이다. 시간 상한은 성능 보장이 아니다.

180회·240회에서 전체 복구 checkpoint를 검증한다. 매6회 로컬 checkpoint를 외부에 누적 업로드하지 않는다. 같은 실행 환경에서 최신 완료 단계 또는 그 이후 최신 복구본 하나만 선택하고, Drive에는 기존 폴더·비공개 권한을 사용한다.100MiB 초과 archive는64MiB 이하 조각과 복원 manifest로 보관하며 로컬 재결합 SHA-256, 원격 크기·권한 검증 범위를 구분한다.

기존 보존 정책을 따른다. 평가 자산·첫 전체60회·최신 전체 checkpoint·그 이후 최신 복구본 하나·최근 파생 후보2개·최신 연구1개 및 모든 복원 의존성을 유지한다. 기존 파생 후보가 의존하는 전체120회도 보존한다. 새 전체 백업을 모두 검증한 뒤에만 대체된 중간 백업을 정리하고, 필수 의존성을 보존한 결과가2GiB 목표를 넘으면 알리고 필수 파일을 삭제하지 않는다.
