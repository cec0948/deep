# NoRegrets 로컬 실행 검증

검증일: 2026-11-05.

## 선택 이유

https://github.com/conorarmstrong/noregrets 는 표준 52장 덱, 2~6인, 100BB, Linear MCCFR, blueprint 파일 저장과 로컬 play/eval을 제공한다. 별도 PostgreSQL이나 전체 카드 추상화 DB를 먼저 생성할 필요가 없어, robopoker보다 작은 기능 시험을 빠르게 할 수 있다. 기존 학습 blueprint의 상용 제공도 명시한다.

이것은 실행·자료 확보 경로에 대한 판단이다. 공개 코드나 상용 모델이 프로급이라는 판단은 아니다. README에 공개된 HU 외부 대전 결과는 상당한 손실을 보이며, 상용 모델의 해당 결과는 아직 받지 못했다.

## 고정한 실행 환경

- 커밋: `757f7692738069522195d2b486eec60a8b010c0c`.
- 공개 소스 라이선스: MIT. 체크아웃 원본과 Cargo.lock 변경 없음.
- Rust 1.90.0, `--locked --release`, 빌드 작업자 최대 4.
- 별도 체크아웃: `.cache/noregrets`. 출력: `artifacts/noregrets-smoke/`.
- 공개 모델은 이 저장소에 포함되지 않는다. 상용 라이선스, 모델 파일, 최신 비공개 소스는 이번 검증에 포함되지 않는다.

## 기능 검사와 진행 상태

재현 명령:

```bash
cd /workspace/deep
bash scripts/try_noregrets.sh
```

스크립트는 다음을 순서대로 수행하며 실패 시 실제 종료 코드를 반환한다.

1. 고정 커밋·원본 변경 여부 확인, 잠금 파일대로 release 빌드.
2. 기존 `engine::tests` 실행. 표준 규칙·사이드팟·랜덤 플레이아웃의 종료/제로섬 검사 포함.
3. 기존 checkpoint 저장·복원·학습 재개 테스트 실행. 이 upstream 단위 테스트 자체는 2인 작은 게임을 사용한다.
4. 6인·100BB에서 200회 학습, blueprint와 checkpoint 저장.
5. 해당 checkpoint를 별도 프로세스에서 읽어 20회 추가 학습.
6. 저장된 전략 파일을 다시 읽어 6인·220회 반복임을 확인.
7. 6인 caller 상대 200핸드 기능 실행.

학습 설정은 4개 raw-equity bucket, equity rollouts 8, runouts 2로 매우 작게 제한한다. 이 모델은 기능 확인용이며 강하지 않다. 200핸드 결과를 성능 평가나 프로급 증거로 쓰지 않는다. EMD k-means, full-size 학습, 온라인 탐색 성능은 이 검사에 포함하지 않는다.

각 build/test/train/resume/inspect/eval에 제한 시간이 있고 로그를 따로 저장한다. 완료 시 `results.json`에 실행한 테스트 수, 모델 반복 수, 파일 크기와 SHA-256을 기록한다.

## 확인한 실행 결과

모든 아래 명령은 종료 코드 0으로 완료했다.

| 검사 | 결과 |
| --- | --- |
| 고정 커밋의 release 빌드 | 성공; upstream 경고 9개, 컴파일 오류 없음 |
| 기존 engine 테스트 | 13 통과, 0 실패; 123개 다른 테스트는 필터로 미실행 |
| 기존 blueprint/checkpoint roundtrip | 1 통과, 0 실패; 135개 다른 테스트는 필터로 미실행 |
| 실제 6인·100BB 학습 | 200회, 6,789개 전략 저장 |
| 별도 프로세스 checkpoint 재개 | 20회 추가, 누적 220회와 6인 설정 확인 |
| 재개 모델의 파일 크기 | 276,150 bytes; 7,572개 전략, 네 스트리트 모두 엔트리 존재 |
| 저장한 모델을 읽은 6인 대전 | caller baseline 상대 200핸드 완료; 강도 평가는 아님 |

실행 기록: `artifacts/noregrets-smoke/run-NK70RShx/results.json` 및 같은 디렉터리의 단계별 로그.
재개 모델 SHA-256: `aca964cdde85e65ba1cf67a21f1484f9364ce5708019b837591dd4ba954f4fbe`.

이 결과로 공개 코드의 로컬 학습·파일 저장·복원·실행 경로를 확인했다. 전체 136개 단위 테스트, 공개 버전의 장시간 학습, 온라인 탐색 및 상용 모델은 검증하지 않았다. 작은 모델의 대전 표본은 너무 작고 상대도 약하므로 수익률을 실력의 증거로 해석하지 않는다.

## 다음 의사결정

우선 기존 상용 blueprint를 평가용으로 받을 수 있는지 확인한다. [문의 초안](commercial-engine-inquiry.md)은 준비했으며 발송하지 않았다. 정확한 6인 모델의 독립 실행·통합 권한, 모델/런타임 버전, 자원 사용, 가격, 평가 자료를 확인해야 한다.

그 결과를 받기 전에 대규모 학습이나 해당 엔진 전용 API에 많은 시간을 투자하지 않는다. 후보가 확정되면 기존 전략 조회 코드를 호출하는 얇은 어댑터를 만들고, 앱의 개인 관측 정보만 전달하는 계약으로 검증한다.
