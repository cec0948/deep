# 학습 기준 구현 검증과 6인 모델 진단

사용자는 매번 성적 향상이 보장되는지, 정책 변화 억제가 올바른 목표인지, 현재 구현과 논문의 차이를 확인한 뒤 후속 검증을 진행하도록 승인했다. 현재 목표는 학습이 개선되는 조건을 검증하고 다음 변경의 근거를 확보하는 것이다. 원래120회 모델과 자기 대전 controller, 네 성능 조건은 보존한다.

## 결과를 보기 전에 정한 실험

설정은 `configs/poker-foundation-study-20261112.json`이다. OpenSpiel1.6.15의 표 형식 CFR과 공식 PyTorch Deep CFR을 2인 Leduc에 적용한다. 상태는 게임의 전체 information-state tensor를 사용하며 기존51차원 요약 특징은 사용하지 않는다. Kuhn보다 복잡한 작은 게임에서 상대의 최적 대응을 정확히 계산하여 exploitability(상대가 전략의 약점을 이용할 수 있는 정도)를 측정한다. 작을수록 좋으며 매 체크포인트의 단조 감소를 요구하지 않는다.

- 표 형식 CFR:500회, 0·10·30·60·120·250·500회에서 평가한다.
- 신경망 Deep CFR:seed71·72·73, 각120회, 플레이어당32 traversals/회, advantage 학습128steps, batch128, 두64-unit 은닉층, memory50,000, learning rate0.001. 각 반복은 두 플레이어를 모두 갱신한다.
- 신경망 체크포인트는0·10·30·60·120회다. 평균 전략 신경망 fitting은 체크포인트에서1,024steps로 수행하고 진단용 fitting이 본 학습의 난수열을 바꾸지 않도록 한다. 실제 정책의 도달 확률 가중 평균과 신경망으로 근사한 평균 전략을 구분한다.
- 합법 행동만 남긴 평균 전략 신경망 출력은 다시 정규화해 평가한다. 이 어댑터와 학습 예산 차이를 기록하며 논문의 완전한 재현이라고 부르지 않는다.
- 사전 sanity 기준: 표 형식 최종 exploitability가 균등 행동의10% 이하, 신경망 세 seed 각각 실제 평균 전략은50% 이하. 평균 전략 신경망도 별도로50% 이하인지 판정하여 학습과 평균 전략 근사 오차를 분리한다. 이는6인 모델 채택 기준이 아니다.
- CPU 단일 thread 프로세스 최대3개, benchmark당900초, 전체 study1,800초 상한. 결과 미달이나 시간 초과를 숨기지 않으며 그 결과에 맞춰 예산·기준을 바꿔 자동 반복하지 않는다.

작은 게임 실험 뒤, 원본 current60·current120·mixture120을 독립적인 호출형·타이트 가치형·공격형의 고정 규칙 상대와 비교한다. 3정책×3seed×3상대=27셀, 각2,000deals×6좌석=324,000핸드다. 카드 범위2026140000~2026141999는 이전 모든 실험과 중복을 검사한다. 같은 카드에서 좌석을 바꾸어 비교하고, 공통 deal 안에서 seed를 평균한 뒤 불확실성을 계산한다. 상대 규칙은 결과를 보기 전에 고정하며 모델에 맞춰 조정하지 않는다.

이 상대들은 학습 가중치를 공유하지 않는 행동 진단용 기준이다. 강한 독립 상대나 프로 수준 상대가 확보됐다고 표시하지 않는다. 원시 핸드 손익·합법 행동·칩 보존을 확인하고 제한된 행동 trace와 상황별 집계로 해석 가능성을 높인다. 원래 네 성능 조건을 대체하거나 통과했다고 표시하지 않는다.

## 입력 정보 손실 점검

현재 모델은 카드·보드·베팅 이력을51개 값으로 요약한다. 실제 게임 엔진에서 합법적으로 도달한 서로 다른 이력이 완전히 같은 특징으로 인코딩되는지 검사한다. 충돌이 발견돼도 두 상황의 최적 행동이 반드시 다르다거나 이번 성적 하락의 원인이라고 단정하지 않는다. 표본의 street·stratum 분포와 실제 정책 출력도 함께 기록한다.

## 독립 상대 확보의 한계

검토한 주요 출처에서 즉시 호환되며 강도가 검증된6인·100BB NLHE 공개 체크포인트를 확인하지 못했다. 이는 그러한 모델이 존재하지 않는다는 결론은 아니다.

- [Pluribus 저자 공개 논문](https://noambrown.com/papers/19-Science-Superhuman.pdf)은 코드 비공개를 명시한다. 의사코드와 핸드 기록은 실행 가능한 정책이 아니다.
- [Eric Steinberger의 Deep CFR](https://github.com/EricSteinberger/Deep-CFR)의 공개 FHP 예제 정책은 축소된 플롭·리밋 게임용이며 현재6인 전체 NLHE와 호환되지 않는다.
- [PokerRL](https://github.com/EricSteinberger/PokerRL)은 연구 프레임워크이며 검토한 문서에 검증된6인 사전학습 정책이 제공되지 않는다.
- [OpenSpiel](https://github.com/google-deepmind/open_spiel)은 이번 작은 게임의 기준 알고리즘과 정확한 최적 대응 평가에 사용한다.

정책·checkpoint·대량 원시 기록은 비공개 artifacts에 두고 공개 저장소에는 소스·설정·집계 결과를 기록한다. 기존 Drive 보존 정책을 유지하며 매 checkpoint를 별도 업로드하지 않는다.
