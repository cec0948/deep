# 리버 콜 모델의 후속 학습

**11월 27일, 후속 정책을 플레이 경로에 적용했다.** 독립 평가 상대 두 종류에서 전날 채택한 리버 모델보다 대상 결정당 평균 **+0.247 bb**를 얻었다. 95% 구간은 **+0.162~+0.332 bb**였다. 해당 국면에 도달하지 않은 패도 포함해 상대와 시드에 같은 비중을 주면 이 변경의 관측 기여는 **100핸드당 +0.527 bb**였다. 이 수치는 두 상대에 대한 이전 모델과의 수익 차이다. [최종 선택과 원자료 집계](../reports/preflop-followup/480-v1/river-call-continuation-20261127/selection.json)

| 검증 상대 | 처음 본 리버 결정 | 이전 모델 대비 결정당 bb | 해당 테이블에서 관측한 100핸드당 기여 |
| --- | ---: | ---: | ---: |
| 공개 Fullhouse | 768 | +0.144 | +0.368 bb |
| SolverLike 행동 규칙 | 768 | +0.350 | +0.687 bb |

무엇이 수익을 높였는지 같은 패에서 확인했다. 이전 가중치로도 승산과 콜 가격 차이가 충분할 때 그 판단을 더 자주 행동에 반영하면 결정당 +0.251 bb였다. 그 강도를 동일하게 고정했을 때 새로 학습한 계수의 추가 효과는 −0.004 bb(95% 구간 −0.021~+0.013)였다. 이번에 재현된 이득은 주로 이전 모델이 이미 잘 구분하던 콜과 폴드 선택에 더 많은 확률을 준 데서 나왔다. 두 정책 모두 레이즈 확률을 유지했다. [독립 검산](../reports/preflop-followup/480-v1/river-call-continuation-20261127/independent-audit.json)

### 실행

```bash
python scripts/run_poker.py --backend river-call-continuation \
  --policy artifacts/preflop-followup/480-v1/river-call-continuation-20261127/play/seed-342/policy.json
```

시드 342·343·344의 일반 JSONL 입력 18개와 잘못된 입력 3개로 선택된 모델을 확인했다. [실행 경로 검증](../reports/preflop-followup/480-v1/river-call-continuation-20261127/play-ready.json)

새 모델, 부모 모델에 대한 참조, 실행 코드와 결과를 비공개 Drive 파일 하나(26,733바이트)에 보관했다. 세 시드의 리버 결정 43개에서 복원한 모델의 행동과 확률이 원본과 일치했다. 원격 크기와 소유자 전용 권한을 확인했고, Drive는 원격 체크섬을 제공하지 않았다. 기존 복구본과 의존성을 포함한 전체 관리 용량은 2,130,092,023바이트로 2 GiB 이내다. [백업 검증](../reports/preflop-followup/480-v1/river-call-continuation-20261127/backup-verification.json)

### 무엇을 바꿨는가

[11월 26일 모델](poker-street-progress-20261126.md)의 계수, 절편, 입력 정규화를 그대로 불러온 뒤 보정할 값만 0에서 시작했다. 기존 훈련용 쇼다운에 절반의 가중치를, 새로 모은 쇼다운에 나머지 절반을 줬다. 새 표본은 세 시드와 세 유형의 상대에 같은 비중을 줬다. 리버 이전에는 기존 자기대전 전략으로 플레이하고, 리버에서 공격적인 규칙 상대, 강한 패 위주의 규칙 상대, 420회 자기대전 모델의 실제 베팅을 경험하게 했다.

총 517,228판에서 새로운 리버 결정 2,304개를 확보하고, 보관해 둔 훈련 결정 2,304개와 합쳐 11번의 최적화 단계로 가중치를 갱신했다. 검증에는 이들과 분리된 71,612판에서 수집한 1,536개 결정을 사용했다. [수집 기록](../reports/preflop-followup/480-v1/river-call-continuation-20261127/collection-summary.json) · [고정된 가중치와 학습 기록](../reports/preflop-followup/480-v1/river-call-continuation-20261127/candidate.json)

플레이할 때에는 보이는 카드, 판돈, 베팅 이력으로 상대에게서 얻을 쇼다운 몫을 추정한다. 추정값과 콜에 필요한 최소 몫이 **5%포인트 이상** 차이 날 때에만 기존 모델이 반대 선택에 둔 확률의 4분의 1을 옮긴다. 레이즈 확률과, 어떤 상대 패를 만나도 콜 수익이 보장되는 리버 처리는 유지한다. 이번에 검증하는 대상은 새 계수와 이 확률 조정을 함께 적용한 정책이다.

### 검증 방법

학습에서 쓰지 않은 카드와 두 상대를 미리 정했다. 검증 시 다섯 상대 자리는 프리플롭부터 리버까지 공개 Fullhouse 모델 또는 SolverLike 행동 규칙으로 플레이한다. 각 상대와 각 시드에서 도달한 원래 패 하나당 한 번만, 동일한 패를 콜과 폴드 양쪽으로 정산한다. 상대의 실제 패는 학습 정답과 결과 검산에만 쓴다.

두 상대와 세 시드에 같은 비중을 주어 이전 모델 대비 칩 차이를 계산한다. 도달한 결정당 평균의 95% 하한이 0을 넘고, 도달하지 않은 판의 차이를 0으로 포함한 100핸드당 평균 기여도 양수일 때만 새 모델을 플레이에 연결한다. [학습량·카드 범위·선택 기준](../reports/preflop-followup/480-v1/river-call-continuation-20261127/design.json)
