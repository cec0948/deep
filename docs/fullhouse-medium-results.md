**작은 기능용 예산보다 확대 학습의 성능은 개선됐다.** 이번 상대/평가 조건에서는 600회−작은 100회 차이의 명목 구간이 0보다 높다. 작은 실험에서 개선이 보이지 않았다는 사실로 학습량 확대의 효과를 부정할 수 없었다는 점이 확인된다. 다만 반복·순회·회귀·buffer 예산을 함께 늘렸으므로 개선 원인을 하나로 분리하지 않는다.

**공개 모델에는 아직 못 미쳤고, 이번 실행 안에서 120→600회에 따른 일관된 추가 개선은 확인되지 않았다.** 따라서 600회를 최선의 모델로 승격하지 않았다. 한 학습 seed와 한 NoRegrets 상대 field에서의 결과이며, 프로급 강도·전체 포커 exploitability·다중 후보 선택 후 일반화를 입증하지 않는다.

## 여전히 관측되는 병목

최종 평균 전략 replay 표본 200,000개의 가중치 ESS는 약 **156.70**, 상위 1% 가중치 점유율은 **89.39%**다. 중요도 가중치 집중도는 확대 학습에서도 남아 있다. 이는 기술 통계이며 같은 trajectory의 history 상관성까지 고려한 독립 표본 수가 아니다. 강도 plateau의 원인이 이 현상 하나라고 단정하지 않는다.

현재 근거에서 다음 우선순위는 독립 seed 재현, 같은 예산으로의 collector/회귀 비교, 상태·좌석·street coverage와 특징 충돌 계측이다. CPU 병렬화/Numba 경로와 NoRegrets의 MCCFR·탐색 경로를 비교해 장기 대여 예산을 정한다. 이 결과만으로 GPU·CPU 임대 규모나 프로급 도달 기간을 확정하지 않는다.

## 이번 환경 오류와 파일 보존의 구분

11월 9일 일시적으로 executor configuration capabilities 조회/시작 오류가 발생했다가, 같은 environment ID가 다시 running/connected가 됐다. **실제 확인 결과 기존 파일은 남아 있었다.** 별개로 11월 6일의 평가 중단 원인은 `small-100` 평가 첫 reset의 엔진 응답 timeout이었다. 같은 코드·같은 파일을 재실행하자 남은 평가가 완료됐다. timeout의 내부 원인은 확인하지 못했다.

현재 환경의 자동중지·삭제/보관기간은 상태 정보에 표시되지 않는다. 이 사건을 파일 자동삭제의 증거로 해석하지 않고, 영구보관이나 상시 실행을 보장하는 근거로도 사용하지 않는다. 같은 환경 안의 `.tar.gz`는 별도 복사본이지만 환경 전체 소실에 대비한 독립 보관은 아니다. 실제로 내려받아 다른 저장소에 보관해야 한다.
