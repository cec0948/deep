# 표본·학습 예산을 유지하는 평균 전략 기준 실험

최신 결과(2026-11-16 17:47 KST, 중단): 첫372회 평균 신경망 품질 기준에2/3seed가 미달했다. 전체420회 학습과36셀 성능 평가는 완료되지 않았다. 자동 재실행·기준 완화·모델 교체를 하지 않았고 모든 소유 프로세스의 종료를 확인했다. 아래는 결과 확인 전에 고정한 계획과 실제 검증 기록이다.

사용자는 논문과 현재 구현의 차이를 설명받은 뒤2026-11-16 “제대로 처리해주세요”라고 요청했다. 이번 작업은 기존360회 복구본을 연결해 새 자기대전을60회 수행하고, 같은 학습 경로의 최신 정책과 새 구간의 평균 전략을 비교한다. 이전에 미달한256steps 후보의 재실험이 아니다.

## 이번에 바로잡는 범위

이전 rich 실행은 입력51→2,885, 보존 표본100,000→5,000행/좌석, 탐색256→64, fitting1,024×512→256×128을 함께 바꿨다. 후속 통제 진단에서 표본 축소·batch 축소·추가 입력의 악화가 해당 고정 자료 안에서 확인됐다. 이 결과만으로 이전 온라인 실행의 악화 원인 하나를 확정하지 않는다.

이번에는 기존51차원 입력·regret 학습기·첫 UTG 전문가를 그대로 사용하고, 표본·탐색·fitting 예산도 유지한다. 바뀌는 학습 구성은 별도로 수집·근사하는 평균 전략뿐이다. 입력 정보 손실과 기존 조건부 regret projection은 남아 있다. 따라서 논문 전체 재현·6인 수렴 보장·실력 향상 완료로 표현하지 않는다. 이 기준선을 확인한 뒤 입력 표현과 탐색을 각각 비교할 근거를 만든다.

기존 학습이 정책을 개선하는 자료와 평균 전략을 근사하는 기준 궤적을 구분한다. 기준 궤적에서는 실제 행동을 모든 선수에 대해 균등하게 뽑고, 저장하는 표적은 해당 시점 학습 정책의 행동 확률이다. 표본 가중치는 절대 반복번호t×해당 선수의 실제 정책 own-reach다. 기준 궤적의 방문 확률q는 학습 정책과 무관하게 고정돼 있어 완전기억 정보집합 안에서 평균을 정규화할 때 공통 인자가 상쇄된다. 다른 선수의 정책 방문 빈도를 그대로 평균 가중치로 쓰거나 큰 역확률을 자르지 않는다.

이 성질은 완전한 정보집합의 평균 추정량에 대한 것이다.51차원 입력이 서로 다른 공개 이력을 합치는 문제는 이번에도 남으며, 신경망은 그 입력에서의 근사다. 표본에서의 평균근사TV≤0.15는 일관성 검사이고 독립 대전 성능 판정이 아니다.

부모 복구본에는360회까지의 전체 정책 이력이 없다. 새 평균은 **업데이트 전 정책361~420만의 도달 확률·t가중 평균**이며,420회 전체 역사 평균이라고 부르지 않는다. 모델 가중치를 산술 평균하지 않고 과거 모델을 매회 저장하지 않는다. 평균 수집과 fitting은 전용 RNG를 사용해 원래 regret 학습의 표본·초기화·난수 소비를 바꾸지 않는다.

## 사전 검증

새 수집기·유계 replay·평균 신경망·NumPy export를 별도 경로에서 검사한다. 실제 작은 게임의 regret 학습은 기존 full-tree 공유 신경망 경로이며, 새 평균 신경망 표적은 새 수집기가 뽑은 표본에서만 얻는다. 작은 게임 통과가6인 regret 학습 전체나 실력 검증이라는 뜻은 아니다.

- 2인·3인Kuhn의 모든 경로를 열거해 평균 추정량의 기댓값과 별도 own-reach 정의를 비교한다. 최대 오차<1e−12를 요구하고, 잘못된 on-policy 방문빈도 평균이 다른 값을 내는 음성 대조도 포함한다.
- Leduc seed71·72·73,32회, 매회1,024기준 궤적, 평균신경망2,048steps×batch512다. 사전에 고정한 조건은 정보집합 가중TV≤0.15, 평균신경망 exploitability가 균등 행동의50% 이하이면서 정확한 학습 궤적 평균+0.35 이하,NumPy/Torch 확률 차이<2e−5다. 세seed 모두 요구하며 결과를 보고 기준을 변경하지 않는다.
- 기존360회 자료에서 원래 동결 worker의 실제 loop를 한 번 실행하고, 새 수집기를 넣은 경로의 같은 업데이트와 가중치·regret replay·첫 행동 통계·4종 난수 상태가 바이트 단위로 같은지 비교한다.1,024×512와256traversals를 축소하지 않는다. 이 그림자 업데이트는 본 실행 진도로 재사용하지 않는다.
- 평균 export로 공개·혼합·NoRegrets20카드×6좌석,360핸드의 실제 행동·손익을 신뢰 엔진에서 재현한다. 이것은 프로토콜 검사이며 후보 성능 판정이 아니다. 사전 검사 카드는2037180000~2037180019로 본 평가와 겹치지 않는다.

## 논문과 남은 차이

[Deep CFR](https://proceedings.mlr.press/v97/brown19b/brown19b.pdf)의 평균 전략 신경망과 regret 표본의 역할을 구분한다. 이번 변경은 작은 고정 평균 메모리·네트워크를 추가하는 제한된 기준선이다. 원래 논문의 완전한 정보 상태,선수별 가치 근사,큰 표본·최적화 예산과 그대로 같지 않다. 게임·실행 예산이 다른 반복 수를 논문의 반복 수와 직접 비교하지 않는다.

[Pluribus](https://noambrown.com/papers/19-Science-Superhuman.pdf)는 표 형태의 추상화 blueprint와 실시간 탐색을 결합한다. 현재 구현의 제한된2인 리버5~10초 파일럿을 그 전체 탐색과 같다고 보지 않는다. 다음 입력·탐색 변경은 이 기준 결과와 실제 병목을 확인한 뒤 한 조건씩 비교해야 한다. 새로운 기법을 여러 개 합친 뒤 좋아질 것이라고 가정하지 않는다.
