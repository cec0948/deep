# 첫 플롭·턴 학습과 리버 콜 개선

**실제 플레이에는 기존 첫 플롭과 480회 턴에 새 리버 콜 모델을 연결했다.** 세 시드의 자기대전 상대 풀에서 리버 베팅을 받아 콜이나 폴드로 끝낼 수 있는 1,152개 국면을 독립 검증했다. 기존 전략보다 해당 결정당 **+0.489 bb**였고, 95% 구간은 **+0.244~+0.734 bb**였다. 세 시드의 평균은 각각 +0.634, +0.426, +0.407 bb였다. [최종 선택과 시드별 결과](../reports/preflop-followup/480-v1/river-call-learning-20261126/selection.json)

기존 플롭 보정 모델이 카드를 더 많이 경험하면 행동 선택이 좋아지는지, 그 정책을 통해 도달한 턴에서도 새로 배울 이득이 있는지 순서대로 살펴봤다. 플롭은 이미 학습한 세 시드의 가중치에서 이어가고, 턴은 별도의 첫 턴 행동가치 모델을 학습한다. 프리플롭과 각 보정 결정 이후의 행동에는 기존 480회 전략을 사용한다. 새 모델을 적용한 첫 턴에서는 이후 리버까지 기존 전략으로 플레이한다.

### 리버에서 막은 손실

리버에서 두 명만 남고 콜로 베팅이 끝날 때, 상대가 가질 수 있는 990가지 두 장 조합을 계산한다. 어떤 패를 만나도 콜 수익이 폴드보다 높으면 기존 모델이 폴드에 준 확률을 모두 콜로 옮긴다. 팟을 나눌 때에는 각 사이드 팟의 홀수 칩까지 감안한다. 자기 패와 공개 정보만 사용한다.

실제 게임 입력으로 쿼드 에이스 사례를 재현했다. 팟 145 bb에 콜 비용이 54.5 bb인 상황에서 한 모델은 3분의 1 확률로 폴드했다. 이 보드에서는 쿼드 에이스를 이기거나 비길 상대 패가 없으므로 폴드 확률을 0으로 바꾸면 **그 국면에 도달했을 때의 기대수익이 48.33 bb** 오른다. 따로 고정한 일반 자기대전 10,800판에서는 두 명이 남아 베팅을 받은 리버 결정이 205개였다. 그중 두 국면에서 콜이 보장됐고, 두 번 모두 기존 모델도 폴드 확률이 0이었다. [재현할 수 있는 패와 베팅 내역](../reports/preflop-followup/480-v1/street-progress-20261126/river-dominance.json) · [자연 대국 발생 빈도](../reports/preflop-followup/480-v1/river-natural-20261126/summary.json)

두 거리의 새 가중치와 선택 기록은 기존 복구본에 연결된 비공개 파일 129,928바이트에 저장했다. 세 시드를 복원해 142개 상태의 행동과 확률을 원본과 대조했다. Drive에서 크기와 소유자 전용 권한을 확인했다. 원격 해시는 제공되지 않았다. 리버 실행 코드는 Git에 보관한다. [백업 검증](../reports/preflop-followup/480-v1/street-progress-20261126/backup-verification.json)

### 학습 방법

플롭에서는 시드마다 기존 1,024개 국면에 새 국면 3,072개를 더한다. 기존 두 신경망의 가중치와 입력 정규화를 그대로 읽은 뒤 각각 768번 갱신한다. 턴에서는 먼저 사용할 플롭 정책을 확정한 뒤, 그 정책으로 실제 도달한 첫 턴 3,072개씩에서 새 신경망을 학습한다. 행동은 기존 포커 모델의 합법적인 메뉴에서 선택하며, 두 신경망 모두 유리하다고 추정할 때 기존 행동 분포에서 한 선택으로 옮기는 확률은 최대 25%다.

각 학습 국면에서 동일한 패로 가능한 모든 선택을 한 번씩 강제하고, 각 선택에서 네 번의 후속 플레이로 최종 손익을 계산한다. 턴에서는 이미 보인 네 번째 공개 카드를 고정하고 남은 카드에서 리버를 새로 뽑는다. 가려진 상대 패는 학습 손익을 계산하는 시뮬레이터에서만 쓴다. 상대 자리는 현재 480회 전략과 세 과거 전략(300·360·420회)으로 구성한다.

### 결과를 판단하는 방법

지표는 **해당 첫 플롭 또는 첫 턴을 만났을 때, 바뀐 한 번의 결정이 가져오는 평균 손익 차이**다. 단위는 결정당 빅블라인드다. 같은 패에서 각 행동의 최종 손익에 새 정책과 부모 정책의 선택확률 차이를 곱해 더한다. 모든 단계에서 하나의 패를 한 표본으로 계산하고 세 시드에 같은 비중을 준다. 이 수치는 이 자기대전 상대 구성에 대한 국면별 효과다.

학습과 분리한 개발 카드 3,072국면에서 평균이 양수인 경우에만, 따로 떼어 둔 최종 카드 4,608국면을 연다. 각 행동에서 같은 여덟 번의 후속 카드를 사용한다. 결과를 보기 전에 플롭·턴 각각의 최종 하한을 평균 − 1.96 × 표준오차로 정했다. 하한이 양수인 단계만 플레이 경로에 연결한다. [카드 범위·학습량·선택 기준](../reports/preflop-followup/480-v1/street-progress-20261126/design.json)

### 베팅을 받은 리버의 콜 학습

이 후속 모델은 상대 패를 모르는 상태에서 콜을 결정한다. 먼저 보이는 일곱 장으로 가능한 상대 패 990개를 열거해 무작위 패에 대한 승점(승리 1, 무승부 0.5)을 구한다. 그다음 실제로 베팅한 상대의 패가 무작위 패와 얼마나 다른지 학습한다. 학습 입력은 베팅 크기, 올인 여부, 앞선 액션, 보드와 같은 공개 정보다. 학습용 정답을 만들 때는 시뮬레이터에서 실제로 나눠준 상대 패를 쓰며 플레이 프로그램에는 전달하지 않는다.

대상은 리버에서 두 명이 남아 상대의 첫 베팅을 받고 콜로 끝낼 수 있는 국면이다. 레이즈 확률을 유지한 채 폴드 또는 콜에 주던 확률의 4분의 1만 반대 선택으로 옮긴다. 독립 확인에서는 각 원래 패를 두 번 정산해 실제로 콜했을 때와 폴드했을 때의 칩 차이를 구한다. 최종 1,152국면의 시드별 평균에 같은 비중을 주고, 사전에 정한 95% 하한이 양수일 때만 학습된 선택을 적용한다. [학습량·입력·선택 기준](../reports/preflop-followup/480-v1/river-call-learning-20261126/design.json)

훈련에서는 원래 핸드 240,375개 중 해당 국면 2,304개를 확보했다. 무작위 상대 패를 가정한 평균 쇼다운 몫은 51.7%였다. 실제로 베팅한 상대에게서 얻은 몫은 동점의 절반을 포함해 35.5%였다. 이 차이를 학습한 모델의 파라미터는 1,165바이트다. 독립 평가용 카드 수집은 일부 학습과 동시에 진행됐으며, 학습기는 훈련 원장만 읽었고 가중치를 고정한 뒤 한 번 채점했다. [학습 영수증](../reports/preflop-followup/480-v1/river-call-learning-20261126/candidate.json)

검증 국면 1,152개 중 200개에서 콜 확률을 높이고 286개에서 낮췄다. 확인한 국면 전체에서 평균한 이득은 두 변경에서 각각 +0.179 bb와 +0.310 bb였다. 검증 국면을 얻기 위해 나눠 준 123,375개 패에서 이 결정에 도달하지 않은 패의 변화량을 0으로 두면, 해당 수정의 관측 기여는 세 시드 동일 가중 평균 +0.673 bb/100이다. 다른 상대군이나 전체 게임 승률은 이번 실험에서 측정하지 않았다. [원자료 독립 검산](../reports/preflop-followup/480-v1/river-call-learning-20261126/independent-audit.json)

채택한 리버 모델과 실행 코드, 선택 기록을 21,945바이트의 비공개 복구본 하나에 저장했다. 세 시드의 리버 결정 42개에서 복원 전후의 행동과 확률이 일치했다. 원격 크기와 소유자 전용 권한, 비공개 인덱스 등록을 확인했다. Drive는 원격 체크섬을 제공하지 않았다. 기존 복원 의존성을 포함한 총 관리 용량은 2,130,065,290바이트로 2 GiB 이내다. [리버 복구본 검증](../reports/preflop-followup/480-v1/river-call-learning-20261126/backup-verification.json)

관련 회귀 테스트 43개가 통과했다. 기존 100만 회 모델을 지정해 저장소 전체 테스트를 실행한 결과 489개 통과, 1개 실패였다. 실패한 11월 16일 후보 테스트는 현재 환경에 이미 결과가 있는 평가 카드 범위를 다시 준비하려다 중복 방지 검사에서 중단됐다.
